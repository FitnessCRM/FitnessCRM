# FitnessCRM

Repositorio `FitnessCRM`, paquete `fitness-crm`. La app se llama por el valor de `APP_NAME` en
`lib/i18n/es.ts`. Reglas, stack y estructura en `CLAUDE.md`; dominio en `docs/dominio.md`;
estado del arranque en `docs/estado.md`.

```
pnpm install
pnpm dev          # desarrollo
pnpm build        # producción
pnpm test         # Vitest
pnpm lint         # ESLint
pnpm typecheck    # tsc --noEmit
```

Node 22 y pnpm.
